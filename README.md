# 🎓 Smart Exam Portal

An online examination system developed using **Python, Flask, SQLite, HTML, CSS, Bootstrap 5, and JavaScript**. This application allows students to take MCQ-based exams online and enables administrators to manage student records with ease.

## ✨ Features

- 🔐 Student Registration & Login
- 👨‍💼 Admin Login
- 📝 Online MCQ Examination
- 📊 Automatic Score & Percentage
- 🏆 Instant Pass/Fail Result
- 👨‍🎓 Student Records Management
- 🔍 Search Students
- 🎯 Filter Records (All / Pass / Fail)
- 📈 Statistics Dashboard
- 📱 Responsive Design

---

## 🛠️ Tech Stack

- **Programming Language:** Python
- **Framework:** Flask
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
- **Deployment:** PythonAnywhere
